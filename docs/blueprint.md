# **App Name**: SkillSlate

## Core Features:

- Home Page: Display a brief introduction, welcome message, and a professional image.
- About Me: Present a summary of the user's background, skills, and career aspirations.
- Project Showcase: Showcase key projects with descriptions, links to demos/repositories, and images.
- Skill Visualization: List technical and soft skills with visual representation of proficiency levels.
- Resume Download: Provide a downloadable PDF version of the user's resume.
- Contact Form: Implement a contact form or display a professional email address for inquiries.
- Profile Linker: Link to the user's social media profiles.

## Style Guidelines:

- Primary color: Deep sky blue (#3498db), evoking professionalism, approachability, and reliability.
- Background color: Light gray (#ecf0f1) providing a clean, neutral backdrop that ensures readability and focuses attention on the content.
- Accent color: Soft lavender (#9b59b6) highlighting interactive elements while complementing the primary color, adding a touch of modernity.
- Body: 'PT Sans', a humanist sans-serif, should be used in order to make text readable and offer a warm look.
- Headline: 'Playfair', a modern serif, should be used in order to deliver elegance with high readability
- Simple, modern icons that align with the portfolio's overall aesthetic.
- Subtle, tasteful animations when content loads, when buttons are clicked, or for transitions, for better engagement and overall feel.
- Clean and professional UI
